02 MétodoMethod

Zero falso positivo. Todo achado vem com prova. Zero false positives. Every finding ships with proof.

Trabalho guiado por impacto: nenhuma hipótese vira relatório sem um teste de reprodução determinístico e uma correção recomendada.

Impact-driven work: no hypothesis becomes a report without a deterministic reproduction test and a recommended fix.

  1. 01

    Escopo e reconhecimentoScope and recon

    Ativos, impactos elegíveis, auditorias anteriores e issues conhecidas são mapeados antes da primeira linha de código.

    Assets, eligible impacts, prior audits and known issues are mapped before the first line of code is read.

  2. 02

    Verificação de invariantesInvariant verification

    Revisão manual que liga cada ponto de entrada público a uma consequência mensurável. Matemática de ponto fixo, encoding e código low-level são superfície de primeira classe.

    Manual review that ties every public entry point to a measurable outcome. Fixed-point math, encoding and low-level code are first-class surface.

  3. 03

    Prova determinísticaDeterministic proof

    Reprodução em ambiente local isolado, comparando o caminho esperado com o caso de borda. Nunca em mainnet ou testnet pública.

    Reproduction in an isolated local environment, comparing the expected path against the edge case. Never on mainnet or a public testnet.

  4. 04

    Revisão cética e relatórioSkeptic review and report

    Validação adversarial independente antes de qualquer entrega. O relatório traz causa raiz, impacto medido e correção recomendada.

    Independent adversarial validation before anything ships. The report carries root cause, measured impact and a recommended fix.

  • ConfidencialidadeConfidentiality

    Nenhum detalhe de achado é publicado. Este site mostra apenas números agregados.

    No finding details are ever published. This site shows aggregate numbers only.

  • Divulgação responsávelResponsible disclosure

    Safe Harbor e políticas de VDP seguidos à risca em todo engajamento.

    Safe Harbor and VDP policies followed to the letter on every engagement.

  • Ambiente isoladoIsolated environment

    Testes rodam em fork local ou ambiente offline. Sistemas em produção não são tocados.

    Tests run on a local fork or offline environment. Production systems are never touched.
